四步完成首次接入

  1. 创建本站 API Key在“API 密钥”页面创建；登录密码和卡密都不能代替 API Key。
  2. 选择协议并填写地址按客户端类型使用上方对应地址，留意是否需要 /v1 或 /v1beta。
  3. 获取并复制模型使用客户端的模型列表或下方命令，模型名称照返回结果填写。
  4. 先发普通文本先关闭工具调用等高级选项，确认基础请求成功后再逐项启用。
先确认 Key 能读取模型把 YOUR_API_KEY 替换成本站 API Key；从返回的 id 复制模型名称。
curl {{station_url}}/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"

先确认模型名和能力

模型名称请从 /v1/models 返回的 id 原样复制。图片生成请选择本站已开放且支持生图的模型；不要把图片模型当作视频模型使用。获取模型列表成功只代表地址、Key 和模型列表接口可访问，不代表每种生成能力都已开通。

快速排查

401 认证404 路径429 频率/额度502/503/504 服务端524 源站连接
现象 先做什么 不要做什么
401 重新复制 Key，核对认证头 不要把卡密或登录密码当 Key
404 看最终 URL；OpenAI 到 /v1，Claude 不加 /v1 不要同时改协议、路径和模型
429 降低并发，查余额，等待后有限重试 不要连续刷新、无限重试
502/503/504 等 10–30 秒后重试，必要时换模型 不要重复创建 Key
524 等待片刻后有限重试；持续失败时记录时间和请求路径，联系站点管理员 不要高频刷新或持续并发请求
模型列表为空 检查 Base URL、Key、分组和模型权限 不要将帮助页面地址填入 API Base URL
页面空白 Ctrl + F5，直接打开 /help 不要把 /help 当 API 地址

故障排查

4xx：优先检查请求、认证与权限

4xx 通常说明请求在进入模型前被拒绝，但也可能来自网关策略、分组设置或上游限制，不能只凭状态码判断责任方。

  • 400 Bad Request： 检查 JSON、参数名、模型能力和请求参数。
  • 401 Unauthorized： 检查 Key 是否完整、是否启用，以及认证头格式。
  • 403 Forbidden： 检查 Key 分组、模型权限、来源限制和上游账号状态。
  • 404 Not Found： 检查协议与路径，尤其是是否出现 /v1/v1；也可能是当前分组不支持该接口。
  • 413 Payload Too Large： 减小图片、附件、上下文或一次生成数量。
  • 429 Rate Limit： 降低并发并检查余额、配额和上游限流，等待后再有限重试。

5xx：优先检查服务、上游与超时

  • 500 Internal Server Error： 服务端或上游处理异常；保留响应内容与请求时间。
  • 502 Bad Gateway： 网关没有获得有效上游响应，稍后重试或切换可用模型。
  • 503 Service Unavailable： 服务过载、维护或上游暂不可用。
  • 504 Gateway Timeout： 请求处理超过网关等待时间；先降低请求复杂度并避免重复提交。
  • 524 Origin Connect Timeout： Cloudflare 未能及时连接源站；等待后重试，并检查源站与网络状态。

推荐排查顺序

1. GET  /v1/models                    验证 Key、DNS 和网络
2. POST /v1/chat/completions          stream=false 的普通文本
3. 用模型列表中的 id 重试
4. 再开 stream、图片、工具或 Agent
